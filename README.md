# Real Estate Market Intelligence Platform

**Status:** Planned

This project analyzes apartment sales in Île-de-France using France’s open
property transaction data. The dashboard will compare median price per
square meter and transaction volume across municipalities and over time.

The first version will cover two departments and focus on transactions
involving a single apartment. It will show transaction counts alongside
price indicators to make the strength of each comparison visible.

**Stack:** PostgreSQL, SQL, Power BI Desktop  
**Data:** [Demandes de valeurs foncières (DVF)](https://www.data.gouv.fr/datasets/demandes-de-valeurs-foncieres)  
**Deliverables:** SQL transformations, Power BI dashboard, and metric methodology.
